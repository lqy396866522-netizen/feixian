# 首页 UI 重构：今日执行目标（P0–P4）

## 目标与范围

把当前首页从“素材堆叠的战斗 Demo”重构为有统一视觉语言、清晰信息层级和可持续扩展的竖屏仙侠挂机首页。设计分辨率为 **720×1280**，运行层仍由 Cocos UI 绘制；AI 生成的视觉稿和图片只作为背景、边框、图标等素材来源，**不承载中文、数值或交互状态**。

视觉母版：`docs/design/ui_home_visual_master_v1.png`。

## P0 — 视觉系统定稿（先做）

**状态：已建立。** 视觉令牌与首页母版已落盘；后续新增素材必须遵守本节约束。

### 设计令牌

| 类别 | 规范 |
|---|---|
| 主底色 | 深蓝墨玉，HUD、任务、聊天和底栏使用同一底色系 |
| 边框 | 克制的古金细边；只用于一级容器与选中态，禁止每个元素都加重描边 |
| 高光 | 青玉/青蓝，只表示可点击、选中、进度或法力 |
| 警示 | 红点和伤害数字仅用暖红色，不与普通金色信息混用 |
| 文本 | 白色正文、浅金标题、金色选中；Cocos `Label` 输出，不写进 AI 贴图 |
| 图标 | 无文字、透明底、同一圆形金边容器；图标本体简洁、识别优先 |

### 尺寸令牌

| 组件 | 规范尺寸 |
|---|---:|
| 顶部资源胶囊 | 120×40 |
| 侧栏活动入口 | 64 图标 + 80×22 标签区 |
| 右上主城/地图 | 60 图标 + 80×22 标签区 |
| 底栏普通 Tab | 60 图标 |
| 底栏主 Tab | 92 图标，独立金色选中光圈 |
| 红点 | 14×14，固定右上角内缩 4px |

### P0 验收

- 不同区域只使用一套深蓝、金、青玉色板。
- 同类功能入口尺寸、标签基线和红点位置一致。
- 所有动态中文、数值、状态均可由代码刷新。

## P1 — 页面信息层级与布局骨架（本轮实现）

**状态：已完成代码布局。** 顶栏、任务、侧栏、操作区、聊天和 Tab 已按下方层级重锚定；最终截图验收需在 Cocos Creator 预览中完成。

### 固定层级

1. **世界层**：地图、角色、怪物、掉落与战斗特效。
2. **顶栏 HUD**：头像、角色摘要、三种资源、菜单与战力；固定在顶部安全区。
3. **关卡任务层**：关卡名、短进度轨和一条主线任务，固定在 HUD 下方中央。
4. **功能栏**：左右各一列活动入口；右上主城/地图；两侧下方为核心快捷操作。
5. **战斗操作层**：击杀目标、技能槽与境界/自动；不得遮挡角色战斗中心。
6. **消息与导航层**：聊天条置于底部 Tab 上方；七 Tab 贴底。

### 本轮具体改造

- 顶栏高度收为 136px，角色信息、资源与战力保持同一水平节奏。
- 关卡标题、进度轨、任务条压缩为连续的三层中心信息区，减少横条数量。
- 左右活动栏固定在任务区下方、战斗区两侧，统一 80px 槽位、84px 间距；不再延伸到顶部 HUD 或底部操作区。
- 主城与世界地图作为右上两枚标准入口，并与右栏保持同一图标语言。
- 战斗操作条移至底栏上方，击杀目标为独立短胶囊；技能槽居中，境界/自动保留在左右两端。
- 底栏使用统一深蓝底座，七个 Tab 等距；中央“玩法”仅一个突出选中态。

### P1 验收

- 角色和怪物所在的屏幕中部区域无横幅遮挡。
- HUD、关卡任务、侧栏、操作区、聊天、Tab 六层互不重叠。
- 720×1280 与窄屏裁切时，所有边缘功能入口仍落在安全区域。

## P2 — 可复用组件化（后续）

**状态：基础已具备。** `HudTopView`、`SideRailsView`、`StageQuestView` 与 `TabBarView` 已是独立组件；新增入口应继续通过数据项和回调接入，而非写回 `MainGame`。

必须形成并复用以下组件：

1. `HudTopView`：头像、角色摘要、货币胶囊、战力。
2. `SideRailsView`：活动入口、主城/地图、红点与锁定态。
3. `StageQuestView`：关卡标题、进度轨、单一主线任务。
4. `TabBarView`：默认、选中、禁用、红点四种状态。

验收：新增入口只填数据与回调，不复制坐标、描边、红点绘制逻辑。

## P3 — 素材替换与图集整理（后续）

**状态：已开始。** 已补齐右上一级入口的无文字贴图：`side_city.png`（主城）与 `side_worldmap.png`（世界地图）。`SideRailsView` 已使用这两个既有路径，Cocos 自动导入后会替代“城 / 图”字符占位。

- 先补齐同一批次的 HUD 框、侧栏入口、Tab 图标和任务面板；每批素材使用同一提示词、同一色板、同一描边尺度。
- 贴图仅包含图形，不包含中文、数字、红点、进度值和锁定文案。
- 正式文件落在 `assets/resources/textures/ui/product/`，代码路径统一为 `textures/ui/product/<name>`。
- 生成后检查透明通道、边缘裁切、导入类型与 1×/2× 显示清晰度。

## P4 — 战斗可读性（后续）

**状态：首项已完成。** 世界层新增位于地图之上、角色之下的轻墨绿遮罩；它不影响角色、怪物、血条和特效的亮度。角色与怪物最终尺寸仍须以 Creator 实机预览截图为准。

**状态更新：** 已新增并接入 `hero_v2.png`、`mob_bird_v2.png`、`mob_turtle_v2.png`。三张精灵清除了棋盘格背景并裁掉了无效边界；代码按有效主体重新设定显示盒，避免原始 1024×1024 透明画布把角色与怪物缩放得忽大忽小。

- 地图亮度/饱和度下调，使角色、怪物、血条和技能高于背景对比度。
- 主角屏幕高度目标为战斗可视区的 18%–22%；普通怪物为主角 55%–70%。
- 血条、选中圈、伤害字、特效有固定排序，不允许互相覆盖或盖住 HUD。
- 地图保持高清原图分块与原生显示，禁止将低分辨率背景放大到全屏。
