# 产品图 UI 规格（720×1280 竖屏）

参考：商用竖屏修仙挂机产品图。坐标系：Canvas 中心为 (0,0)，**Y 向上**（与 `MainGame` / Cocos UI 一致）。

## 区域划分（自上而下，互不重叠）

坐标见 `assets/scripts/ui/ProductLayout.ts`。画布中心为原点，Y 向上，半高 640。

| 区域 ID | 名称 | Y 范围 | 说明 |
|---------|------|--------|------|
| R01+R02 | 顶栏 HUD（含战力） | 522 ~ 634 | 头像/货币/菜单在带内，不溢出 |
| R03 | 地图、主城 | 右侧 x≈318，y≈424/488 | 避开关卡条中心列 |
| R06+R07 | 关卡 + 任务横幅 | 394 ~ 504 | 宽度收进中心，不盖右侧入口 |
| R04+R05 | 左右活动栏 | y≈138~330，x≈±328 | 只占战斗带两侧 |
| R08+R09 | 战斗区 + HP 条 | 角色脚 y≈28；HP 条 y≈248 且宽 400 | 不盖侧栏、不盖任务条 |
| R10~R12 | ActionDock | -505 ~ -295 | 击杀条、技能、自动劫、突破 |
| R13 | 世界聊天 | -518 ~ -482 | 在 Tab 之上 |
| R14 | 七 Tab | -640 ~ -528 | 贴底，不盖聊天 |

## Tab 顺序（左→右）

1. 角色 `role`
2. 装备 `equip`
3. 法术 `spells`
4. 异兽 `beasts`
5. 玩法 `play`（选中态金色）
6. 洞天 `cave`（Toast 未开放）
7. 仙盟 `alliance`（占位）

**设置**：汉堡菜单 → 全屏设置层（原 `guild` Tab 内容）。

## 资源路径约定

贴图根：`assets/resources/textures/ui/product/`  
代码中：`textures/ui/product/<name>`（无扩展名）。
